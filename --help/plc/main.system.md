# Help System Description

## 项目身份
- **项目名称**：Help
- **项目代号**：`--help`
- **所属行业**：教学 / 样机
- **部署场所**：实验台
- **最终用户**：控制工程师
- **监管要求**：无

## 系统使命
这是一套最小 RustPLC 启动项目，用于把系统意图、PLC 逻辑、场景、I/O 映射和交付产物组织成完整工程。

## 安全与可靠性定位
- **安全等级**：常规工业防护
- **故障后果**：演示失败或设备误动作
- **容错策略**：等待超时后进入 safe stop

## 运行环境
- **介质**：数字 I/O 演示
- **电源**：DC 24V
- **控制器**：RustPLC + RP2040 示例链路
- **通信**：无
- **环境条件**：室内调试环境

## 核心工艺意图

### 正常流程
1. 等待启动输入 `X0`
2. 启动后置位输出 `Y0`
3. 延时 20ms 后关闭输出
4. 流程结束并停机

### 异常处理
- 若启动信号在 100ms 内未到达，则进入 `fault` task 执行安全关闭。

### 特殊工况
- 当前骨架未启用手动模式、维护模式与并发 task。

## 并发与阻塞语义假设
- **并发 task 划分**：当前仅 `main` 与 `fault/done` 这类简单控制流
- **blocking step 清单**：`wait`、`delay`
- **阻塞隔离预期**：后续若拆分并发 task，某 task 阻塞不得阻塞其他 task
- **共享资源边界**：`Y0` 为当前唯一执行输出

## 启动与停机流程

### 上电初始化
- 上电后默认输出全关，等待启动信号。

### 正常停止
- 正常流程结束后关闭 `Y0` 并进入 `done`。

### 急停流程
- 本骨架未建模独立急停，实际项目应补充硬件急停与安全回路。

### 单步模式
- 当前未提供，调试阶段可借助 trace 观察 step 推进。
