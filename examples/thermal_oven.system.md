# thermal_oven.system.md

## 项目身份
- 项目名称：温控烘箱控制系统
- 所属行业：工业制造 / 热处理
- 部署场所：生产车间烘箱工位
- 最终用户：工艺工程师 / 操作员
- 监管要求：常规工业安全防护，超温保护符合 IEC 60519 电热设备安全标准

## 系统使命
本系统控制烘箱加热器，通过 PID 闭环将腔体温度精确维持在 150°C 设定值，完成工件保温工艺。失效后果为工件烘烤不足（质量问题）或超温损坏工件及设备（财产损失），不涉及人身伤害风险，但超温需立即联锁保护。

## 安全与可靠性定位
- 安全等级：常规工业防护（非 SIL 认证）
- 故障后果：超温可能损坏工件和加热器，欠温导致工艺不合格
- 容错策略：单一超温硬限（180°C）立即关闭加热器并报警；所有 wait 均有 timeout 保护

## 运行环境
- 介质：空气（干燥热风循环）
- 电源：220V AC 单相，加热器通过固态继电器（SSR）控制
- 控制器：工业 PLC，配备模拟量输入模块（热电偶/PT100）
- 通信：本地操作面板
- 环境条件：室温 20~40°C，相对湿度 ≤ 85%

## 核心工艺意图

**正常流程：**
1. 操作员按启动按钮，系统进入加热阶段
2. 加热器开启，PID 控制器将温度升至设定值 150°C
3. 等待温度传感器读数 ≥ 145°C（进入稳定区间）
4. 保温 5000ms（固定延时，确保工件均匀受热）
5. 保温结束后判断温度：
   - 若温度 ≥ 145°C → 正常完成，进入 complete 流程
   - 若温度 < 145°C（温度跌落）→ 重新加热，进入 reheat 流程
6. 完成后关闭加热器，等待腔体冷却至 50°C 以下，回到就绪状态

**异常处理：**
- 超温保护：温度超过 180°C 时，fault_handler 立即关闭加热器并触发报警
- 所有等待步骤均有超时保护，超时后跳转 fault_handler

**特殊工况：**
- 重新加热最多允许一次（通过 reheat task 实现），避免无限循环
- 冷却阶段允许较长等待时间（timeout 120000ms）

## 关键约束
- 超温硬限：AI_temp > 180 时加热器必须关闭（safety conflicts_with）
- 加热器开启时 PID 必须处于激活状态（逻辑保证，非 DSL 约束）
- 保温时间：固定 5000ms delay
- 温度稳定判据：AI_temp >= 145°C
- 冷却完成判据：AI_temp < 50°C
- 升温超时：10000ms（从启动到达温）
- 冷却超时：120000ms（自然冷却）

## 设计偏好
- 命名语言：中英混合（设备名英文，注释中文）
- 代码风格：每步骤职责单一，注释清晰
- 时序参数策略：超时 = 预期时间 × 2，留足余量
- 扩展预期：后续可增加多段温度曲线（多 step 顺序升温）

## 对 AI 的指引
- 本项目安全等级为常规工业防护，不需要双冗余传感器
- 超温保护通过 safety 约束 + fault_handler 双重保障
- PID 设备使用 `pid` 类型，关联 AI_temp（pv）和 heater_out（AO，加热器功率指令）
- 加热器开关使用 `digital_output`，通过 SSR 控制
- if-else 分支用于保温后的温度判断，两个分支都必须有 goto 目标
- ready task 使用 allow_indefinite_wait 等待操作员启动
- fault_handler 必须关闭加热器（set heater off）并记录报警日志
