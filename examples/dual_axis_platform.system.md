# dual_axis_platform.system.md

## 项目身份

- 项目名称：双轴运动平台控制系统
- 所属行业：工业自动化 / 精密定位设备
- 部署场所：制造车间，用于工件搬运、点胶、检测等工位
- 最终用户：设备操作员 / 工艺工程师
- 监管要求：常规工业安全防护，无特殊行业认证要求

## 系统使命

本系统控制一台 X/Y 双轴步进电机运动平台，实现工件的精确二维定位。系统负责回原点、运动到目标位置两个核心流程，并通过碰撞防护互锁确保 X 轴和 Y 轴不会同时运动。失效后果为工件定位错误或机械碰撞，导致设备损坏和生产中断。

## 安全与可靠性定位

- 安全等级：常规工业防护（非 SIL 认证）
- 故障后果：机械碰撞导致设备损坏，生产停线
- 容错策略：单一超时保护 + 故障处理任务（停止所有电机，等待人工复位）

## 运行环境

- 驱动方式：步进电机驱动器（脉冲+方向信号）
- 传感器：限位开关（原点传感器、到位传感器）
- 控制器：通用工业 PLC
- 电源：24VDC 控制电源
- 通信：无上位系统通信要求
- 环境：室内工业环境，无特殊防护要求

## 核心工艺意图

**正常流程：**
1. 上电后等待操作员按下启动按钮
2. 回原点流程：X 轴先回原点（向负方向运动，等待 X 原点传感器触发），然后 Y 轴回原点（等待 Y 原点传感器触发）
3. 运动到目标位置：X 轴和 Y 轴同时启动运动（parallel 并行），分别等待各自的到位传感器
4. 到位确认：使用 race 块检测 X 轴到位信号或超时哪个先发生，确认 X 轴定位完成
5. 完成一个定位循环后回到等待状态

**异常处理：**
- 任何 wait 超时 → 停止所有电机 → 输出报警日志 → 等待人工复位

**碰撞防护：**
- X 轴电机运动状态（motor_x.on）与 Y 轴电机运动状态（motor_y.on）互斥，不能同时为 on

## 关键约束

1. 碰撞防护：motor_x.on conflicts_with motor_y.on（X/Y 轴不能同时运动）
2. 回原点顺序：X 轴先回原点，Y 轴后回原点（顺序执行保证）
3. 目标定位：X/Y 轴同时运动到目标位（parallel 并行）
4. 整个定位循环（homing + 运动到位）必须在 8000ms 内完成
5. 所有 wait 必须有 timeout 保护，超时跳转到 fault_handler

## 设计偏好

- 命名语言：中英文混合（设备名英文，purpose 中文）
- 代码风格：参考当前 examples 中 `plc_main + relation` 的建模模式
- 时序参数：电机 ramp_time 50ms，原点回归超时 3000ms，到位超时 3000ms
- 扩展预期：后续可能增加 Z 轴，命名预留扩展空间

## 对 AI 的指引

- 碰撞防护约束是本系统最重要的安全规则，必须用 `safety: motor_x.on conflicts_with motor_y.on` 表达
- parallel 块用于 X/Y 同时运动到目标位，race 块用于检测 X 轴到位 vs 超时
- 由于 conflicts_with 约束，parallel 块内的两个分支不能同时触发 motor_x 和 motor_y 的 on 状态——需要在 parallel 之前分别启动电机，parallel 内只放 wait
- 时序约束使用 `must_complete_within`（基于实际动作时间），不使用 worst_case 变体
- fault_handler 必须停止 motor_x 和 motor_y 两个电机
- ready 任务等待启动按钮，标记 allow_indefinite_wait
