## 项目身份

- 项目名称：焊接工作站自动控制系统
- 所属行业：汽车/金属制造
- 部署场所：生产车间焊接工位
- 最终用户：焊接工位操作员及设备维护人员
- 监管要求：符合 GB/T 15706 机械安全通用设计原则，常规工业防护等级

## 系统使命

本系统控制一套气动焊接工作站，完成"夹紧→焊接→冷却→松开"的完整工艺节拍。操作员放置工件并按确认按钮后，系统自动执行夹紧、焊接、冷却、松开全流程，每次节拍重复 3 次后停止等待下一次人工确认。系统失效可能导致工件未夹紧时焊枪下降，造成工件损坏或人身伤害。

## 安全与可靠性定位

- 安全等级：常规工业防护（非 SIL 认证，但需要基本互锁保护）
- 故障后果：工件损坏、焊枪碰撞、轻微人身伤害风险
- 容错策略：
  - 每个自动动作均有超时保护，超时后跳转 fault_handler 安全复位
  - 焊枪下降与夹紧缸之间设置 conflicts_with 互锁（焊枪下降时夹紧缸不得松开）
  - 人工确认步骤使用 allow_indefinite_wait，不设超时

## 运行环境

- 介质：压缩空气（0.4~0.6 MPa）
- 电源：24V DC 控制电源
- 控制器：通用工业 PLC（数字 I/O）
- 通信：本地 I/O，无网络通信
- 环境条件：室内车间，温度 5~45°C，防护等级 IP54

## 核心工艺意图

**正常流程（每节拍重复 3 次）：**
1. 操作员将工件放置到焊接夹具上，按下确认按钮（人工操作，允许无限等待）
2. 夹紧缸 A 和夹紧缸 B 同时夹紧工件（parallel 并行动作）
3. 焊枪下降到焊接位置
4. 焊接动作持续 3000ms（固定延时）
5. 焊枪抬起复位
6. 冷却风扇开启，等待冷却传感器确认或延时 5000ms（取先到者）
7. 夹紧缸 A 和夹紧缸 B 同时松开（parallel 并行动作）
8. 以上步骤重复 3 次（repeat 3）

**异常处理：**
- 任何自动动作超时 → 跳转 fault_handler
- fault_handler：焊枪抬起、夹紧缸松开、风扇关闭，输出报警日志，回到 ready 等待

**特殊工况：**
- 急停后需人工复位，重新按确认按钮才能继续

## 关键约束

1. 焊枪下降（cyl_weld.extended）与夹紧缸松开状态互斥：焊枪下降时，夹紧缸 A 和 B 必须保持夹紧（requires）
2. 夹紧缸 A 和夹紧缸 B 的夹紧动作不与焊枪下降冲突（顺序控制保证：先夹紧再焊接）
3. 冷却完成条件：冷却传感器 on 或延时 5000ms（OR 条件，取先到者）
4. 每个自动 wait 必须有 timeout 保护
5. repeat 3 不能嵌套在 parallel/race 内部

## 设计偏好

- 命名语言：中英混合（设备名英文，purpose 中文）
- 代码风格：参照 assembly_station.plc 的 relation 模式
- 时序参数：按默认值（电磁阀 20ms，气缸 300ms，超时 1.5x）
- 扩展预期：后续可能增加焊接质量检测传感器

## 对 AI 的指引

- 本项目为常规工业防护，不需要双冗余传感器，单传感器即可
- repeat 3 必须放在顶层 task 的 step 中，不能嵌套在 parallel 内
- parallel 块用于夹紧缸 A+B 同时动作，但 repeat 包裹整个工艺循环
- 冷却等待使用 OR 条件（sensor_cool == true OR delay 5000ms），实际 DSL 中用 race 块实现：一个分支等传感器，另一个分支等延时
- 所有 safety 约束：焊枪下降 requires 夹紧缸 A 夹紧，焊枪下降 requires 夹紧缸 B 夹紧
- fault_handler 必须覆盖所有执行器的安全复位（焊枪抬起、夹紧缸松开、风扇关闭）
