# hydraulic_bender.system.md

## 项目身份

- 项目名称：液压折弯机控制系统
- 所属行业：金属加工 / 钣金制造
- 部署场所：钣金车间，折弯工位
- 最终用户：钣金操作工，设备维护工程师
- 监管要求：符合 GB/T 15706 机械安全通用设计原则，液压系统参照 GB/T 3766

## 系统使命

本系统控制液压折弯机的完整折弯循环：液压缸快速下行接触工件后切换慢速加压，PID 闭环将系统压力稳定在 60 bar 设定值，保压 2000ms 后快速回程复位。系统失效可能导致工件折弯角度不合格（欠压）或模具/工件损坏（超压），严重时造成液压管路破裂和人身伤害。

## 安全与可靠性定位

- 安全等级：常规工业防护（SIL1 参考），超压保护为硬性安全约束
- 故障后果：超压（>90 bar）可导致液压管路破裂、模具损坏，存在人身伤害风险；欠压导致折弯角度不合格
- 容错策略：
  - 超压硬限：压力超过 90 bar 立即停止并报警，不可绕过
  - 所有 wait 均有 timeout 保护，超时跳转 fault_handler
  - fault_handler 负责关闭液压阀、泄压并报警
  - 整个折弯循环有 15000ms 最坏情况时序约束

## 运行环境

- 介质：液压油（HM46），系统压力 0~100 bar
- 液压源：液压泵站，额定压力 100 bar
- 电源：AC 220V 控制电源，DC 24V I/O 电源
- 控制器：工业 PLC（兼容 RustPLC runtime-core）
- 传感器：压力变送器（4~20mA，量程 0~100 bar），行程接近开关
- 执行器：液压比例阀（模拟量控制开度），液压缸（快速/慢速两段控制）
- 环境：室内车间，温度 5~45°C，防护等级 IP54

## 核心工艺意图

**正常折弯循环：**
1. 操作员放置工件后按启动按钮
2. 液压缸快速下行（比例阀大开度），行程传感器检测到接触工件位置后停止快速下行
3. 切换到慢速加压模式（比例阀小开度），PID 控制器将压力闭环到 60 bar 设定值
4. 等待压力稳定（AI_pressure >= 58 bar），进入保压阶段
5. 保压 2000ms，维持折弯角度
6. 快速回程：关闭加压阀，液压缸快速缩回到原位（行程传感器确认）
7. 循环完成，等待下一次启动

**异常处理：**
- 任何步骤超时 → fault_handler：关闭比例阀、泄压、报警、回到 ready
- 压力超过 90 bar → 立即触发超压保护，停止所有动作并报警

**特殊工况：**
- 上电初始化：液压缸必须在原位（sensor_hyd_ret == true），否则不允许启动
- 急停：操作员可随时按急停，系统进入 fault_handler

## 关键约束

1. 超压保护：AI_pressure > 90 bar 时，禁止继续加压动作（conflicts_with 约束）
2. 时序约束：整个折弯循环（task.cycle）必须在 15000ms 内完成（must_complete_within_worst_case，含所有超时上界）
3. 顺序互锁：必须先检测到工件接触位（sensor_hyd_contact），才能切换到加压模式
4. 保压时间：固定 2000ms delay，不可缩短
5. 回程确认：必须等待 sensor_hyd_ret == true 才算循环完成

## 设计偏好

- 命名语言：中英混合（设备名英文缩写，purpose 中文描述）
- 代码风格：参照 analog_pressure_demo.plc 和 pid_loop.plc 的模拟量模式
- 时序参数策略：超时 = 动作时间 × 1.5，保守估计
- 扩展预期：后续可能增加折弯角度补偿（extern function）和多段折弯程序

## 对 AI 的指引

- 本项目是工业生产设备，超压保护是硬性安全约束，必须用 `safety:` 声明
- PID 控制器用于压力闭环，参照 pid_loop.plc 模式
- 液压缸用 `cylinder` 类型建模，快速/慢速通过比例阀开度（set_analog）区分
- 行程传感器用 `sensor` + `limit_switch` 建模
- 所有 wait 必须有 timeout -> goto fault_handler
- fault_handler 必须关闭比例阀（set_analog AO0 0）并报警
- 时序约束用 must_complete_within_worst_case 15000ms（含超时上界）
- analog_input 压力传感器标记 external: true（物理传感器，非 PLC 内部计算）
