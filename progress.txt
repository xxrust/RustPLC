# Ralph Progress Log
## Codebase Patterns
- Keep subtype vocabulary and compatibility rules centralized in `src/device_subtype.rs`; normalize first, then query the matrix rather than scattering subtype literals.
- For DSL attribute migrations, keep legacy keys in AST/parser and map them to the new canonical field during parsing, then emit a migration warning when both are present.
- Topology semantic gate checks should split into per-device preflight validation (attributes/subtypes) and connection validation, so attribute errors surface even without relation edges.
- Canonical sample modeling now maps common discrete inputs by intent: start/reset buttons use `push_button`, cylinder end-stroke feedback uses `limit_switch`, presence/arrival sensing uses `proximity_sensor`, and emergency stops must use `e_stop_button` with `inverted: true`.
- PIL semantic baseline fixtures must keep the directory contract `examples/pil_baselines/<case>/case.plc` + `scenarios/base.yaml`; scripts auto-discover case folders and skip incomplete fixtures.
