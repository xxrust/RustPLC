## Codebase Patterns
- Topology parser now supports mixed entries in `[topology]`; when any explicit `relation { ... }` is present, `TopologySection.connections` should come from relation blocks instead of auto-derived edges.
- Use dedicated parser helpers (`expect_port_reference`, `expect_topology_relation`) for relation fields so errors stay localized to `relation.from` / `relation.to` / `relation.via`.
- Topology relation handling should stay single-source: parser/semantic/topology-gate all consume `TopologySection.connections` only (no attribute-based fallback).
