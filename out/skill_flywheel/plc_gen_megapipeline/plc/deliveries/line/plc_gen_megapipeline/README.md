# Battery Module Pack Line Asset

## Purpose
This line asset is the integration package for a six-station battery module pack line.
It freezes the serial manufacturing route and the parallel station ownership map.

## Key Facts
- Stations: 6
- Positions per station: 4
- Total cylinders + motors: 109
- Line entry: `plc/main.bundle.toml`
- Nominal scenario: `scenarios/nominal/normal.yaml`
