# Board Semantics Contract v1 (RP2040)

This contract freezes the minimum board/runtime behavior that SIL/PIL/board regression gates rely on.

## 1) Tick contract

- One runtime tick equals one call to `Runtime::tick_with_trace_and_logs(...)`.
- Firmware pacing target is `1ms` per tick (`Timer`-based wait to next tick boundary).
- `Io::advance_tick()` is called exactly once per runtime tick (inside `runtime-core`).

## 2) Trace/log contract

Firmware must emit structured lines:

- `TICK tick=<u64> ts_ms=<u64>`
- `TRACE tick=<u64> task=<usize> from=<u16> to=<u16> reason=<str> ts_ms=<u64>`
- `LOG tick=<u64> task=<usize> step=<u16> msg_id=<u16> msg=<str> ts_ms=<u64>`

Host-side tooling assumptions:

- `board-parse` consumes board logs and outputs `board_trace.jsonl` + `tick_timing.jsonl`.
- `trace-diff --fail-on-mismatch` is the regression gate.

## 3) Digital I/O contract

- `io_map.toml` keys: `diN`/`doN`.
- GPIO allowed range: `0..=29`.
- Duplicate GPIO assignment across DI/DO/AI/AO is rejected at build-time.

## 4) Analog input contract

- `io_map.toml` keys: `aiN`.
- RP2040 allowed GPIO range: `26..=29` only (ADC-capable pins).
- Per tick, firmware samples ADC and maps `0.0..3.3V` to engineering units:

  `eng = min + clamp(volts / 3.3, 0..1) * (max - min)`

- `min/max` come from `analog_contract.toml` generated by `build-rp2040`.
- Optional per-channel calibration is applied after mapping:
  - `eng_cal = eng * scale + offset`
  - `scale/offset` live in `analog_contract.toml` (defaults: `1.0/0.0`) and may be overridden
    by an external calibration file via `build-rp2040 --analog-calibration <file>`.

## 5) Analog output contract

- `io_map.toml` keys: `aoN`.
- Firmware drives AO via PWM with per-channel target/ramp semantics.
- Per-channel contract from `analog_contract.toml`:
  - `min/max`: engineering range
  - `ramp_ms`: slew time from range-min to range-max (`0` means immediate)
  - `scale/offset`: optional calibration (`eng_cal = eng * scale + offset`, defaults: `1.0/0.0`)

Mapping to duty:

`duty = clamp((eng - min)/(max - min), 0..1) * PWM_TOP`

## 6) Build artifact contract

`build-rp2040 --out <dir>` emits at least:

- `generated_program.rs`
- `io_map.template.toml`
- `analog_contract.toml`
- `analog_calibration.template.toml`
- `build_meta.json`

For UF2 flow, `build-rp2040 --emit-uf2 ...` injects:

- `RUST_PLC_GENERATED_PROGRAM_RS`
- `RUST_PLC_IO_MAP_TOML`
- `RUST_PLC_ANALOG_CONTRACT_TOML`

into `board-rp2040` firmware build.
