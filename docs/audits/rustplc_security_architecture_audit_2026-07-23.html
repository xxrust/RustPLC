已修复问题

领域原风险当前机制状态
Web 控制面 默认远程监听、缺少鉴权、CORS 边界宽松。 默认 localhost；远程模式要求显式开关、Bearer Token 和来源白名单。 已修复
文件与进程边界 路径逃逸、无限制文件读取、命令输出与任务堆积。 canonical containment、UUID run ID、并发信号量、运行超时、输入/输出/记录上限。 已修复
Semantic 前门 raw I/O 绕过、重复设备、非有限数值、表达式资源消耗和 panic 路径。 源码级门禁、finite/f32 范围检查、表达式深度与节点预算、结构化诊断。 已修复
编译架构 CLI 与 Web 独立拼装 semantic 管线，结果可能漂移。 compile_semantic_program_with_library 成为共享编译入口。 已修复
Runtime 所有权 bridge 使用 Box::leak 满足静态引用，编译程序无法回收。 CompiledRuntimeProgram 使用 Bump + self_cell 持有 runtime 数据。 已修复
并发与 workpiece root task、extern WCET、carrier slot、类型和 pending action 在 runtime/verification 间存在口径差。 共享 graph-based roots、并发 WCET 合计、容量门禁、checked StepId、DeviceAction 生命周期。 已修复
依赖安全 Rust rand 0.8.5 unsound；前端包含 Axios、React Router、DOMPurify、Vite 等漏洞。 升级 axum/tungstenite 与前端依赖；DOMPurify 使用项目 override 固定到修复版本。 已修复
