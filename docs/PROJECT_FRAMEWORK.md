# RustPLC 项目完整框架

> **最后更新**: 2026-07-06
> **版本**: v2.0

---

## 总览

RustPLC 是一个**工业控制系统形式化验证编译器**，通过数学证明保证控制程序的安全性、活性、时序和因果性。

## 关键路径分析

### 从源码到部署

```
.plc 文件
    ↓ Parser (< 50ms)
AST
    ↓ Semantic (< 200ms)
IR
    ↓ Verification (< 1s, 并行)
验证报告
    ↓ Codegen (< 100ms)
ST 代码 / 固件
    ↓ 部署
硬件运行
```

**总编译时间**: 通常 < 1.5s（典型项目）

## 技术栈总览

### 编译器

| 技术 | 用途 |
|------|------|
| Rust | 编译器实现语言 |
| pest | PEG 解析器生成器 |
| petgraph | IR 图数据结构 |
| Z3 | SMT 求解器（Safety 引擎） |
| rayon | 并行计算 |
| serde | 序列化/反序列化 |

### 运行时

| 技术 | 用途 |
|------|------|
| no_std Rust | 确定性运行时 |
| embassy | RP2040 异步框架 |
| Renode | 虚拟硬件仿真 |
| tokio | 异步 I/O (仿真) |

### 工具链

| 技术 | 用途 |
|------|------|
| Axum | Web UI 后端 |
| clap | CLI 参数解析 |
| toml | 配置文件格式 |
| yaml | 场景定义格式 |

## 开发者快速索引

|------|----------|
