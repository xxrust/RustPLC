真实残余风险

  • unattended_verdict=not_proven：缺少文件级前后 digest 归因链和持久模型标识。
  • fresh_checkout=not_proven：未在 clean clone/clean worktree 中执行最终 runner。
  • Synthetic point observation 只证明 UI/API 路径，不替代接线、仪表测量、HIL 或安全签署。
  • 电子签名是内部 engineering attestation，不声明满足特定法规。
  • 远程/生产部署仍需组织身份、密码哈希和密钥管理。
  • Command palette field:value 过滤需要继续定位 Chrome 实际执行路径。
