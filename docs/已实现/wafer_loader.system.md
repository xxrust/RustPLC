# 测角机上料器系统语义描述

> 本文件是测角机上料器控制工程的顶层语义描述。
> 后续 PLC DSL、runtime bridge、verification 与 codegen 均应以本文件为基线，不得回退为隐式单执行点模型。

## 项目身份

- **项目名称**：测角机上料器
- **所属行业**：半导体
- **部署场所**：普通洁净车间
- **最终用户**：半导体产线操作员
- **监管要求**：无专门监管要求

## 系统使命

本系统负责将晶片从出料盒稳定取出，经辨相台完成数字 1/0 判定与 180 度翻转选择后，送入测片台，持续为测角机提供方向正确、姿态正确的单片上料。

本系统失效的主要后果是晶片损失、掉片、节拍中断或设备干涉，不以人身安全为主风险，因此控制策略优先保证不撞机、不误送片、可追踪告警与可恢复生产。

## 安全与可靠性定位

- **安全等级**：常规工业防护，无 SIL 等级要求
- **故障后果**：晶片损失、设备节拍中断、潜在机构干涉
- **容错策略**：
  - 气缸不到位以告警/警告方式挂起，修复后由操作员点击屏幕刷新状态并自动续跑
  - 步进轴故障优先执行有限次自动复位；若仍无法恢复，则告警停机
  - 晶片掉落按连续次数与长期掉落率双阈值管理
  - 辨相异常晶片丢入 IR 盒；连续 3 片异常则告警后停机

## 运行环境

- **介质**：气动 + 步进轴
- **气源**：0.4 MPa
- **电源**：220V AC 输入，经 24V DC 开关电源输出
- **控制器**：Keyence KV-5500
- **通信**：
  - 气缸与电机：I/O 信号控制
  - 显示器/HMI：以太网
- **环境条件**：普通洁净车间

## 核心工艺意图

### 正常流程

系统按“出片准备 -> 旋臂取片与辨相 -> 转运至测片台”组织主流程：

1. 出料机构前移到取片位。
2. 出料机构打开真空并保持吸附，随后后退，使单片晶片停留在滑轨/取料位。
3. 小旋臂从 IR 盒中间初始位旋转到滑轨侧取片位，吸取晶片。
4. 小旋臂旋转到辨相台上方，将晶片放到辨相台并由辨相台吸附。
5. 辨相台光纤输出当前朝向的数字判定结果（1/0）。
6. 辨相台下方旋转气缸动作 180 度，再次读取数字判定结果（1/0）。
7. 控制逻辑按两次数字判定结果决定最终朝向；若当前朝向满足要求，则辨相台回原位；若翻转后朝向满足要求，则保持翻转后位置。
8. 摆缸下摆并下移至取料位，吸取辨相完成的晶片。
9. 摆缸上移、上摆、前移，将晶片送至测片台。
10. 摆缸后移回待机位，等待下一片完成辨相后继续取料。

系统允许在不发生互锁冲突时并发准备下一片，以提升节拍。

### 异常处理

- **未吸到片**：
  - 取片吸附窗口最长 1 秒。
  - 通过真空检测确认是否吸到片。
  - 若 1 秒内仍未吸到片，则停机处理。
- **辨相异常**：
  - 若两次数字判定结果都无法得到可接受朝向，则当前晶片丢入 IR 盒。
  - 若连续 3 片都出现该类异常，则告警后停机。
- **气缸不到位**：
  - 产生警告并挂起当前相关流程。
  - 待气缸或磁性开关修复后，由操作员在屏幕上点击刷新状态，系统自动继续运行。
- **步进轴不到位/运动异常**：
  - 先执行有限次自动复位与恢复。
  - 若恢复后可正常运动，则继续运行。
  - 若在限定次数内仍无法恢复，则告警停机。
  - 自动复位重试次数需在联调阶段冻结。
- **晶片途中掉落**：
  - 单次掉落时记录计数，不回收当前掉落片，直接准备吸取下一片。
  - 连续掉落 2 次则告警停机。
  - 若长期掉落概率超过 1/1000，则告警后停机。

### 特殊工况

- **自动模式**：执行正式上料工艺，允许 `feed_prep`、`orient_stage`、`transfer_to_measure` 按共享资源互锁并发推进。
- **手动模式**：支持单独点动气缸、真空、旋臂与摆缸机构，主要用于单机构检查与联调。
- **单步模式**：按“出片准备 / 取片辨相 / 转运送片”这类关键节拍逐段执行，每次只放行一个调试节拍。
- **维护模式**：允许工程师执行安全位回收、旋臂回零、计数清零等维护动作，但不得绕过防撞互锁。
- **自动测试**：作为自动模式下的测试运行配置，不单独定义另一套脱节工艺逻辑；测试时仍复用正式工艺与异常统计。

### 控制模式矩阵

- **自动模式**：
  - 入口语义：`mode_auto` 有效且收到启动命令后进入自动节拍。
  - 退出语义：收到停止请求或 `mode_auto` 失效后，执行“清料到 IR 盒 + 机构回安全位”。
  - 允许动作：完整工艺节拍、异常统计、自动恢复、正常停机清料。
- **手动模式**：
  - 入口语义：`mode_manual` 有效，且不与其他模式并存。
  - 允许动作：单独前后退气缸、开关真空、旋臂去滑轨位/中间位/辨相位、辨相翻转、摆缸取放动作。
  - 保留约束：旋臂运动前仍需确认出料气缸与摆缸处于安全窗口，不允许以手动名义越过已知碰撞边界。
- **单步模式**：
  - 入口语义：`mode_step` 有效，且不与其他模式并存。
  - 允许动作：按一次命令只执行一个完整调试节拍，例如一次出片准备、一次取片辨相、一次转运送片。
  - 保留约束：单步执行仍复用正式流程中的 timeout、真空确认、到位等待与异常分流。
- **维护模式**：
  - 入口语义：`mode_maintenance` 有效，且不与其他模式并存。
  - 允许动作：安全回位、旋臂回零、统计量清零等维护动作。
  - 保留约束：不得绕过防撞互锁、原点确认与关键状态可见性。
- **模式互斥规则**：
  - 自动、手动、单步、维护四类模式必须逻辑互斥。
  - 模式切换时不得保留未受控的机构运动。
  - 涉及旋臂运动的服务类动作，必须先把出料气缸与摆缸收回到安全窗口。

## 并发与阻塞语义假设

- **并发 task 划分**：
  - `feed_prep`：出料机构出片与滑轨准备
  - `orient_stage`：旋臂取片、放片、辨相测量与 180 度翻转选择
  - `transfer_to_measure`：摆缸从辨相台取片并送入测片台
- **blocking step 清单**：
  - 所有 `wait` 传感器到位等待
  - 所有 `delay` 保压/稳定等待
  - 旋臂 `axis.move_*` 运动等待
  - 真空吸附确认等待
- 辨相台数字 1/0 判定结果等待
  - 操作员刷新状态后的恢复等待
- **阻塞隔离预期**：
  - 某个 task 在 `wait/delay/axis.move_*` 或外部反馈中阻塞时，不得阻塞其他无互锁冲突 task 的推进。
  - 只有命中共享资源互锁时，相关 task 才需要显式让行。
- **共享资源边界**：
  - 片盒前进 与 旋臂向滑轨端移动互斥，防止撞机。
  - 摆缸下摆 与 旋臂向辨相台旋转互斥，防止撞机。
  - 辨相台吸附面为 `orient_stage` 与 `transfer_to_measure` 的共享交接资源。
  - 在不占用上述共享资源时，允许提前准备下一片。

## 启动与停机流程

### 上电初始化

1. 关闭所有真空。
2. 出料气缸后退。
3. 其他相关气缸退回安全位，包括后退、上摆、后移等初始姿态。
4. 待所有气缸回到安全位置后，执行旋臂回零。
5. 旋臂通过原点传感器回零；原点位于逆时针极限方向，且比辨相台位置更逆。
6. 辨相台在初始化时不要求固定朝向，可保留当前位或在后续工艺中重新确立方向。
7. 初始化完成后进入待机状态，等待自动启动命令。

### 正常停止

1. 接收停止请求后，不再引入新的上料节拍。
2. 系统将当前在制片按“清料到 IR 盒”原则有序处理完毕。
3. 清料完成后，各机构回到初始化安全位置。
4. 关闭真空并进入停止待机状态。

### 急停流程

基于当前需求，工艺控制层不单独定义软件急停流程。

- 本项目默认由整机硬件急停链或上位设备安全回路承担急停职责。
- 若后续设备集成要求将急停行为纳入 RustPLC 工艺语义，需单独补充本节并同步 runtime/verification 约束。

## 调试与测试策略

### 手动测试

- 允许单独点动出料气缸、摆缸、辨相台旋转气缸、真空与旋臂。
- 手动模式必须保留防撞互锁，不允许强行执行已知碰撞动作组合。
- 手动点动的旋臂动作应先确认 `cyl_feed`、`cyl_swing` 已退到安全窗口，再允许执行轴运动。

### 自动测试

- 支持完整流程自动测试。
- 自动测试默认复用自动模式，不额外增加独立模式位。
- 需记录吸片成功率、掉片计数、辨相异常计数、运动恢复次数等关键指标。
- 当掉片率超过 1/1000 或异常片连续达到停机阈值时，自动测试也应停机告警。

### 单步模式

- 用于调试节拍和确认传感器行为。
- 单步命令应至少覆盖出片准备、取片辨相、转运送片三个关键节拍。
- 每次只允许执行一个调试节拍，完成后回到等待下一次人工触发。

### 维护模式

- 允许工程师绕过部分节拍联锁进行维护。
- 维护模式不得绕过防撞互锁、原点确认和关键状态可见性。
- 维护模式下应至少支持安全回位、旋臂回零和统计清零。

## 关键约束

### 安全规则

- 片盒前进时，旋臂不得向滑轨端移动。
- 摆缸下摆时，旋臂不得向辨相台方向旋转。
- 旋臂必须在所有相关气缸回到安全位后才允许初始化/回零。
- 任何已知会引发机构干涉的组合动作都必须通过互锁禁止。

### 时序要求

- 吸片确认窗口上限为 1 秒。
- 气缸与步进轴的其它超时值应按现场机械节拍标定，并在 PLC 实现中显式建模。
- 步进轴自动复位重试次数与单次恢复时限需在联调阶段冻结。

### 互锁关系

- 辨相台未准备好时，摆缸不得取料。
- 旋臂未离开辨相台危险区时，摆缸不得下摆。
- 片盒未退回安全位置前，旋臂不得进入滑轨取片区域。
- 真空检测未确认吸片成功时，不得进入后续送片步骤。

## 轴运动补充

- **参数层级**：
  - `model_ref/config_ref/motion_param_set` 由后续轴模型定义统一承载。
  - 当前系统语义已明确“旋臂是必须回零的步进轴”，具体参数集名称待联调冻结。
- **动作覆盖策略**：
  - 允许后续在动作内覆盖 `speed/acc/dec`，但覆盖边界应由固定参数集约束，避免现场任意改写。
- **故障策略矩阵**：
  - `severity`：以可恢复设备故障为主，失效后主要后果为晶片损失与节拍中断
  - `stop_mode`：优先受控恢复；恢复失败后停机等待处理
  - `auto_reset_policy`：允许有限次自动复位
  - `manual_ack_required`：自动复位失败后需要操作员处理
- **传播策略**：
  - `propagation_scope`：默认 `self`，但停机后会影响整机上料节拍
  - 若后续将旋臂故障传播到整机 fault task，需在 PLC 设计中显式建模
- **回零与软限位**：
  - 旋臂必须先回零再进入自动循环
  - 原点传感器在逆时针极限位置，且比辨相台位置更逆
  - 当前无软限位要求

## 设计偏好

- **命名语言**：中文注释 + 英文标识符
- **代码风格**：控制逻辑清晰、注重工艺可读性
- **时序参数策略**：保守，优先防止撞机与掉片
- **扩展预期**：后续可能继续细化掉片统计、辨相策略和轴恢复策略

## 对 AI 的指引

基于以上背景，在生成 PLC 代码时应遵循以下决策倾向：

- 优先按并发 task 建模，不把 `feed_prep`、`orient_stage`、`transfer_to_measure` 压平成单执行点顺序机。
- 所有阻塞行为必须通过 `wait/delay/axis.move_*` 或显式外部反馈等待建模，不得用隐式轮询副作用替代。
- 旋臂轴运动必须进入 IR、runtime bridge 和 verification 闭环，不允许仅在 runtime 做特例。
- 防撞互锁优先级高于节拍优化；任何并发设计都必须先满足互锁边界。
- 吸片失败、辨相异常、掉片统计和轴恢复都必须有可追踪诊断。
- 停止流程必须实现“清料到 IR 盒”而不是简单就地停机。
- 自动测试模式应复用正式工艺语义，不得另写一套脱节逻辑。
- 输出必须遵守 `docs/architecture/signal-direction.md`：按并发 task + blocking step 组织语义，不回退为单执行点假设。
- 输出必须能进入 `safety`、`liveness`、`timing`、`causality` 四类验证闭环。
